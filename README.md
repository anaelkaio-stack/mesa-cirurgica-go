# Mesa Cirúrgica GO

Jogo educativo de instrumentação cirúrgica em Gineco-Obstetrícia: arraste cada instrumento ao quadrante correto da mesa
(QSE Auxiliares · QSD Síntese · QIE Hemostasia · QID Diérese).

Desenvolvido por Kaio Anael · PUC · Turma 74

## Como publicar no GitHub Pages
1. Suba `index.html`, `.nojekyll` e `README.md` na raiz do repositório.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. O jogo fica em `https://SEU-USUARIO.github.io/mesa-cirurgica-go/`.
